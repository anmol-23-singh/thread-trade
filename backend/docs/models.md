# Data Models

All models are defined using Mongoose and stored in MongoDB Atlas. Each model maps to a collection in the `threadtrade` database.

---

## `User.js`
Represents a registered user of the platform.

| Field | Type | Description |
|-------|------|-------------|
| `name` | String | Full display name |
| `email` | String | Unique login email |
| `password` | String | Bcrypt-hashed password |
| `role` | String | `user` or `admin` |
| `avatar` | String | Cloudinary URL for profile picture |
| `location.city` | String | User's city for local swap matching |
| `location.state` | String | User's state |
| `refreshToken` | String | Stored refresh token for session management |
| `rating` | Number | Average rating from peer reviews |
| `reviewCount` | Number | Total number of reviews received |
| `wishlist` | [ObjectId] | Array of saved listing IDs |
| `createdAt` | Date | Auto-generated by Mongoose timestamps |

---

## `Listing.js`
Represents a clothing item listed for swap.

| Field | Type | Description |
|-------|------|-------------|
| `title` | String | Item title (e.g. "Blue Denim Jacket") |
| `description` | String | Detailed description |
| `category` | String | One of: Shirt, Dress, Jacket, Jeans, Footwear, etc. |
| `brand` | String | Brand name |
| `size` | String | Clothing size (S, M, L, XL, etc.) |
| `condition` | String | New with tags / Like New / Good / Fair |
| `estimatedValue` | Number | Estimated swap value in INR (₹) |
| `images` | [String] | Cloudinary image URLs (up to 6) |
| `owner` | ObjectId | Reference to `User` |
| `location.city` | String | Listing city |
| `location.state` | String | Listing state |
| `status` | String | `available`, `swapped`, or `removed` |
| `tags` | [String] | Searchable tags |

---

## `SwapRequest.js`
Represents a swap proposal between two users.

| Field | Type | Description |
|-------|------|-------------|
| `fromUser` | ObjectId | User who initiated the swap |
| `toUser` | ObjectId | User who owns the desired item |
| `itemOffered` | ObjectId | Listing offered by `fromUser` |
| `itemWanted` | ObjectId | Listing requested by `fromUser` |
| `status` | String | `pending`, `accepted`, `rejected`, `completed`, `cancelled` |
| `message` | String | Optional note from the requester |
| `createdAt` | Date | Timestamp of swap initiation |

---

## `Message.js`
Represents a single chat message within a swap thread.

| Field | Type | Description |
|-------|------|-------------|
| `swapRequest` | ObjectId | Reference to the parent `SwapRequest` |
| `sender` | ObjectId | User who sent the message |
| `text` | String | Message content |
| `createdAt` | Date | Auto-generated timestamp |

---

## `Review.js`
Represents a post-swap rating left by one user for another.

| Field | Type | Description |
|-------|------|-------------|
| `reviewer` | ObjectId | User who wrote the review |
| `reviewee` | ObjectId | User being reviewed |
| `swapRequest` | ObjectId | The completed swap this review relates to |
| `rating` | Number | 1–5 star rating |
| `comment` | String | Optional written feedback |

---

## `Notification.js`
In-app notifications triggered by swap events.

| Field | Type | Description |
|-------|------|-------------|
| `user` | ObjectId | The recipient user |
| `type` | String | Notification type (e.g. `swap_received`, `swap_accepted`) |
| `message` | String | Human-readable notification text |
| `read` | Boolean | Whether the user has seen the notification |
| `link` | String | Frontend route to navigate to |

---

## `Report.js`
A moderation report filed against a listing or user.

| Field | Type | Description |
|-------|------|-------------|
| `reporter` | ObjectId | User who filed the report |
| `targetType` | String | `listing` or `user` |
| `targetId` | ObjectId | ID of the reported resource |
| `reason` | String | Reason for reporting |
| `status` | String | `open` or `resolved` |
| `adminNote` | String | Optional resolution note from admin |

---

## `AuditLog.js`
Immutable log of admin actions for accountability.

| Field | Type | Description |
|-------|------|-------------|
| `admin` | ObjectId | Admin user who performed the action |
| `action` | String | Action type (e.g. `DELETE_USER`, `RESOLVE_REPORT`) |
| `targetId` | ObjectId | Resource that was acted upon |
| `targetModel` | String | Model name of the target resource |
| `timestamp` | Date | When the action occurred |
